# Security policy

Mission Shield `0.2.0-rc.8` is a prerelease for limited customer-owned pilots. It is not a general-availability release.

Report suspected vulnerabilities privately through GitHub private vulnerability reporting for the Mission Shield deployment repository when available. Do not include organization records, databases, backups, exports, credentials, tokens, invitation links, environment files, or other third-party information.

Operators remain responsible for securely configuring identity, HTTPS, secrets, network exposure, backups, monitoring, updates, and recovery in their own Azure account. Blam Labs cannot monitor or administer customer deployments.

Mission Shield should not store beneficiary or client case records, payment-card data, health information, government identifiers, passwords, private keys, or other unnecessary personal information. Prefer metadata and sanitized evidence descriptions.
